## Штатная публикация

Убедитесь, что проверка pylint в Pull Request успешна. Выполните слияние в main, затем откройте Publish documentation на вкладке Actions. После успешного завершения build и deploy откройте URL окружения github-pages.

## Ручной перезапуск

Откройте Actions → Publish documentation → Run workflow и выберите main.

## Диагностика

Определите отказавший этап по журналу. При ошибке Pylint исправьте код, при предупреждении MkDocs проверьте цель относительной ссылки. При успешном build и отказе deploy проверьте права на публикацию.
