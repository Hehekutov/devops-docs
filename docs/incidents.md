# Журнал типовых инцидентов

| Симптом | Этап | Проверка |
| --- | --- | --- |
| Неиспользуемая переменная | CI | Журнал Static analysis |
| Не получен OIDC-токен | Deploy | Журнал Deploy to GitHub Pages, права id-token |
| Битая внутренняя ссылка | Build | Журнал Build documentation |
| Отображается прежняя версия | Pages | URL окружения и файл build.txt |

Укажите симптом, компонент, запись из журнала, причину, исправление и повторную проверку.

Раздел о восстановлении находится в [регламенте эксплуатации](runbook.md).
